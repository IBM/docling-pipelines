# Command Line Interface (CLI)

This application provides a command-line interface for executing data processing flows locally.

## Purpose
- Execute flows from command line
- Local data processing without Spark
- Development and testing workflows
- Lightweight deployment scenarios

## Usage

```bash
python cmd_line_orchestrator.py --flow-file flow.json
```

## Features
- Flow execution from JSON configuration
- Python-based operator execution
- Local file system support
- Plugin system integration
- Logging and monitoring

## Configuration
- Flow definition files (JSON)
- Environment variables
- Configuration files

See the `/examples` directory for sample flow configurations and usage patterns.
