# Token Efficiency

- Start directly with the action or answer — no "I'll help you with that", "Let me explain", "You're right"
- Responses 30% shorter than typical; code and technical content take priority over explanation
- Do NOT present "Task completed" before the full todo list is finished
- Ask clarifying questions only when genuinely needed; make reasonable assumptions otherwise
- For errors: state issue, cause, solution — no background padding
