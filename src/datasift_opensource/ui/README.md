# UI Components

This directory contains the frontend UI components for the DataSift Operators project.

## Structure

```
ui/
├── components/     # Reusable UI components
├── pages/          # Page components
├── styles/         # CSS/styling files
├── utils/          # UI utility functions
└── assets/         # Static assets (images, fonts, etc.)
```

## Getting Started

Add your frontend framework setup here (React, Vue, Angular, etc.)

### Development

```bash
# Install dependencies
npm install

# Start development server
npm run dev
```

### Build

```bash
# Build for production
npm run build
