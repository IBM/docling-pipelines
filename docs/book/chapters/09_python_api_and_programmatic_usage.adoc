== Python API and Programmatic Usage

Docling-pipelines can be used programmatically via `DocpipeFlowManager`, embedded in Jupyter notebooks, or controlled via the FastAPI REST server.

=== DocpipeFlowManager

`DocpipeFlowManager` provides the Python API for flow execution.

==== Setup

[source,bash]
----
export PYTHONPATH="$(pwd)/src:${PYTHONPATH}"
source .venv/bin/activate
----

Verify the import:

[source,bash]
----
python -c "from docpipe.lib.docpipe_flow_manager import DocpipeFlowManager; print('OK')"
----

==== Execute a Flow from File

[source,python]
----
from pathlib import Path
from docpipe.lib.docpipe_flow_manager import DocpipeFlowManager

manager = DocpipeFlowManager(
    flow_file=str(Path("sample_flows/quickstart/complete_pipeline_ollama.json")),
    job_id="my-stable-job-id"      # optional but recommended for incremental runs
)

result = manager.execute()

metadata = manager.get_execution_metadata()
print(f"Job ID: {metadata.get('job_id')}")
print(f"Flow Name: {metadata.get('flow_name')}")
----

==== Execute a Flow from a Dictionary

[source,python]
----
from docpipe.lib.docpipe_flow_manager import DocpipeFlowManager

flow_def = {
    "flow_name": "inline-pipeline",
    "global_config": {
        "doc_column": "content",
        "force_ingest": True
    },
    "flow": [
        {
            "name": "ingest",
            "type": "ingest_source",
            "config": {
                "provider": "filesystem",
                "connection_params": {"paths": ["./documents"]},
                "include_filter": ".pdf,.txt"
            }
        },
        {
            "name": "extract",
            "type": "extract_operator",
            "depends_on": ["ingest"],
            "config": {
                "text_extraction": {"provider": "docling_library"},
                "entity_extraction": {"provider": "none"}
            }
        }
    ]
}

manager = DocpipeFlowManager(flow_def=flow_def, job_id="my-pipeline-001")
result = manager.execute()
----

==== Validate Before Executing

[source,python]
----
manager = DocpipeFlowManager(flow_file="my_flow.json")
validation_result = manager.validate()

if validation_result.is_valid:
    print("Flow is valid")
    result = manager.execute()
else:
    print(f"Validation errors: {validation_result.errors}")
    print(f"Validation warnings: {validation_result.warnings}")
----

==== Accessing Execution Metadata

[source,python]
----
metadata = manager.get_execution_metadata()
print(f"Job ID: {metadata['job_id']}")
print(f"Job Run ID: {metadata['job_run_id']}")
print(f"Flow Name: {metadata['flow_name']}")
print(f"Status: {metadata['status']}")
print(f"Duration: {metadata['duration']}")
----

==== Retrieving Execution Logs

[source,python]
----
logs = manager.get_execution_logs()
for entry in logs:
    print(f"[{entry['level']}] {entry['operator']}: {entry['message']}")
----

==== Listing Available Operators

[source,python]
----
from docpipe.lib.docpipe_flow_manager import DocpipeFlowManager

manager = DocpipeFlowManager.__new__(DocpipeFlowManager)
operators = manager.list_operators(verbose=True)
for op in operators:
    print(f"{op['short_name']}: {op['description']}")
----

Or from the CLI:

[source,bash]
----
docling-pipelines --list-operators
docling-pipelines --list-operators --verbose
----

==== Custom job_id and flow_id

[source,python]
----
import uuid

manager = DocpipeFlowManager(
    flow_file="my_flow.json",
    job_id="finance-pipeline",          # stable; determines incremental state
    flow_id=str(uuid.uuid4())           # unique per run
)
----

==== Error Handling

[source,python]
----
from docpipe.exceptions import (
    FlowValidationException,
    FlowExecutionFailedException,
    DocpipeException
)

try:
    manager = DocpipeFlowManager(flow_file="my_flow.json")
    result = manager.execute()

except FlowValidationException as exc:
    print(f"Validation failed: {exc.errors}")

except FlowExecutionFailedException as exc:
    print(f"Execution failed: {exc}")
    logs = manager.get_execution_logs()
    failed = [l for l in logs if l.get("level") == "ERROR"]
    for entry in failed:
        print(f"  {entry['operator']}: {entry['message']}")

except DocpipeException as exc:
    print(f"Docpipe error: {exc}")
----

==== Log Level Configuration

[source,python]
----
import os
os.environ["DS_LOG_LEVEL"] = "DEBUG"

from docpipe.lib.docpipe_flow_manager import DocpipeFlowManager
manager = DocpipeFlowManager(flow_file="my_flow.json")
manager.execute()
----

Or set before launching:

[source,bash]
----
DS_LOG_LEVEL=DEBUG docling-pipelines --flow-file my_flow.json
----

==== Disabling docpipe Log Configuration (Embedded Usage)

When embedding docpipe in an existing application with its own logging setup:

[source,python]
----
manager = DocpipeFlowManager(
    flow_file="my_flow.json",
    configure_logging=False        # do not let docpipe reconfigure root logger
)
----

=== Jupyter Notebook Integration

[source,python]
----
# Install if needed:
# !pip install docpipe  (or in a venv: !uv pip install -e ".[dev]")

import os
os.environ["PYTHONPATH"] = "/path/to/docling-pipelines/src"
os.environ["DS_LOG_LEVEL"] = "INFO"

from docpipe.lib.docpipe_flow_manager import DocpipeFlowManager

flow_def = {
    "flow_name": "notebook-pipeline",
    "flow": [
        {
            "name": "ingest",
            "type": "ingest_source",
            "config": {
                "provider": "filesystem",
                "connection_params": {"paths": ["./sample_docs"]},
                "include_filter": ".pdf"
            }
        },
        {
            "name": "extract",
            "type": "extract_operator",
            "depends_on": ["ingest"],
            "config": {
                "text_extraction": {"provider": "docling_library"},
                "entity_extraction": {"provider": "none"}
            }
        }
    ]
}

manager = DocpipeFlowManager(flow_def=flow_def, job_id="notebook-001")
result = manager.execute()
metadata = manager.get_execution_metadata()
print(metadata)
----

=== REST API Server

==== Starting the Server

[source,bash]
----
source .venv/bin/activate
export PYTHONPATH="$(pwd)/src:${PYTHONPATH}"

uvicorn docpipe.api.main:app --reload --host 0.0.0.0 --port 8080
----

Once running:

[cols="2,3",options="header"]
|===
|URL |Description
|`http://localhost:8080/health` |Health check
|`http://localhost:8080/api/v1/docs` |Swagger UI (interactive API docs)
|`http://localhost:8080/api/v1/redoc` |ReDoc documentation
|`http://localhost:8080/api/v1/openapi.json` |Raw OpenAPI schema
|===

==== Authentication

Two paths are supported; both produce a JWT that is passed as `Authorization: Bearer <token>`:

[source,bash]
----
# LDAP login
curl -X POST http://localhost:8080/auth/login \
  -H "Content-Type: application/json" \
  -d '{"username": "alice", "password": "${LDAP_PASSWORD}"}'

# Use the token
TOKEN="eyJhbGci..."
curl http://localhost:8080/api/v1/flows \
  -H "Authorization: Bearer ${TOKEN}"
----

See xref:11_production_deployment_and_observability.adoc[Chapter 11] for OAuth2/OIDC setup.

==== API Endpoints Summary

===== Projects

[cols="1,2,3",options="header"]
|===
|Method |Path |Description
|`POST` |`/api/v1/projects` |Create a new project
|`GET` |`/api/v1/projects` |List projects (paginated)
|`DELETE` |`/api/v1/projects/\{id}` |Delete a project (cascade-deletes flows)
|===

===== Flows

[cols="1,2,3",options="header"]
|===
|Method |Path |Description
|`POST` |`/api/v1/flows` |Create a new flow
|`GET` |`/api/v1/flows` |List flows (paginated)
|`GET` |`/api/v1/flows/\{id}` |Get a flow by ID
|`PUT` |`/api/v1/flows/\{id}` |Replace a flow
|`DELETE` |`/api/v1/flows/\{id}` |Delete a flow
|===

===== Job Runs

[cols="1,2,3",options="header"]
|===
|Method |Path |Description
|`POST` |`/api/v1/job_runs` |Create and start a job run
|`GET` |`/api/v1/job_runs/\{id}` |Get job run status
|`POST` |`/api/v1/job_runs/\{id}/cancel` |Cancel a running job
|===

===== Operators

[cols="1,2,3",options="header"]
|===
|Method |Path |Description
|`GET` |`/api/v1/operators/metadata` |List all operators with metadata
|===

===== Documents and Document Libraries

[cols="1,2,3",options="header"]
|===
|Method |Path |Description
|`GET` |`/api/v1/documents/\{id}` |Retrieve a document by ID (ACL-filtered)
|`POST` |`/api/v1/documents/search` |Search documents (ACL-filtered)
|`POST` |`/api/v1/document-libraries` |Create a document library
|`GET` |`/api/v1/document-libraries` |List document libraries
|`GET` |`/api/v1/document-sets` |List document sets
|===

=== CLI API Reference

==== Command Forms

[source,bash]
----
# Execute a flow
docling-pipelines --flow-file <path>

# Validate only (no execution)
docling-pipelines --flow-file <path> --validate

# List all operators
docling-pipelines --list-operators

# List operators with detailed parameters
docling-pipelines --list-operators --verbose

# Specify a custom job ID
docling-pipelines --flow-file <path> --job-id my-job-id
----

==== Exit Codes

[cols="1,3",options="header"]
|===
|Code |Meaning
|`0` |Success
|`1` |Flow execution error
|`2` |Validation error
|`3` |Configuration error
|`4` |Import / dependency error
|===
